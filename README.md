# Custos da Códice

Levantamento de custos do projeto Códice (plataforma, rastreamento por tag, módulo smart ESP32, nuvem e mão de obra), de 09/09 a 23/10/2026.

- `index.html`: deck de 14 telas (palco 1600 x 900, setas do teclado ou botões).
- `detalhes.html`: anexo com cada pedido, nuvem, horas, equivalente de mercado, projeção de escala e simulador.
- `dados.js`: fonte única dos números. Para atualizar (por exemplo, o preço real das tags), mude aqui e os dois arquivos recalculam.
- `calc.js`: contas compartilhadas pelo deck e pelo anexo.

Não contém dados pessoais: só item, quantidade, data e valor de cada pedido.
